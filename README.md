The cleanest, most minimal, production-ready example of modern Android home-screen widgets built with **Jetpack Glance + Compose**.

No XML. No RemoteViews boilerplate. Just pure declarative Kotlin.

Perfect starting point to add a beautiful, clickable, adaptive widget to your Compose app in minutes.

## Why Glance is the future of Android widgets

| Legacy widgets (XML + RemoteViews)      | Glance + Compose                              |
|------------------------------------------|-----------------------------------------------|
| Tons of XML layouts                      | One `@Composable`                             |
| Manual size buckets                      | `SizeMode.Responsive` out of the box          |
| Updates via `AppWidgetManager`           | `actionRunCallback()`, WorkManager, Flow      |
| No Material You or animations            | Full Material 3, Dynamic Color, animations    |
| Painful to preview & test                | `@Preview`, unit tests, instant hot-reload    |

## What's inside

- Fully working widget from scratch
- Clickable areas (whole widget + individual elements)
- Instant live previews in Android Studio (no device needed)
- Clean, copy-paste-ready code
